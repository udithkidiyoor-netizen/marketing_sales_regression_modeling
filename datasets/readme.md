## Data Dictionary

| Column Name | Data Type | Description |
|------------|----------|-------------|
| `TV` | string | Television promotion budget category represented as **Low**, **Medium**, or **High** |
| `Radio` | integer | Radio promotion budget (in millions) |
| `Social Media` | integer | Social media promotion budget (in millions) |
| `Influencer` | string | Influencer category used in the campaign (**Mega, Macro, Nano, Micro**) |
| `Sales` | integer | Total sales generated (in millions) |
